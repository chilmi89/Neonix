# Neonix Color Palette Reference

This document lists the primary colors used in the Neonix platform, inspired by the Tiket.com light professional theme. These colors are defined as CSS variables in `src/styles/globals.css`.

## Core Palette

| Color Name | Hex Code | CSS Variable | Description |
| :--- | :--- | :--- | :--- |
| **White** | `#FFFFFF` | `--background` | Main page background |
| **Tiket Blue** | `#0064D2` | `--primary` | Primary branding color, buttons, links |
| **Sky Blue** | `#00BAFF` | `--accent` | Secondary accent color for fresh highlights |
| **Deep Slate** | `#0F172A` | `--foreground` | Main text color for high readability |
| **Slate 50** | `#F8FAFC` | `--muted` | Light gray for sections and backgrounds |
| **Slate 500** | `#64748B` | `--muted-foreground` | Muted text color |
| **Slate 200** | `#E2E8F0` | `--border` | Subtle border color |
| **Tiket Yellow** | `#FEDD00` | `--color-neon-yellow` | Brand yellow (Tiket-inspired) |
| **Success Green**| `#21D35F` | `--color-neon-green` | Success states and positive actions |

## Glassmorphism System

| Name | Value | CSS Variable |
| :--- | :--- | :--- |
| **Surface** | `rgba(255, 255, 255, 0.7)` | `--glass-surface` |
| **Border** | `rgba(15, 23, 42, 0.08)` | `--glass-border` |
| **Hover** | `rgba(0, 100, 210, 0.03)` | `--glass-hover` |
| **Radius** | `1rem` | `--glass-radius` |

---
*Note: Dark mode overrides have been disabled to maintain this consistent palette.*
